# Giovanni Carta — Personal Portfolio

## Open locally

1. Open a terminal in this folder.
2. Run:

```bash
python start_server.py
```

3. Open `http://localhost:8000` in your browser.

You can also open `index.html` directly, but the Python server is recommended.

## Main files

- `index.html`: homepage content
- `assets/css/style.css`: design and responsive layout
- `assets/js/main.js`: mobile menu and current year
- `projects/`: individual project stories
- `assets/Giovanni_Carta_CV.pdf`: downloadable CV
